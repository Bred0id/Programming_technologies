# Описание задания

## Шаги по выполнению задания

Есть два проекта, которые нам необходимо будет запаковать в Docker-образ и настроить запуск приложений:

- Проект, который собирается при помощи CMake
- Простое приложение на Flask

1. Склонируйте репозиторий: https://gitlab.akhcheck.ru/task-templates/docker-template
2. Переключитесь на ветку `task-docker`.
3. Скопируйте `task-docker` в ваш проект.
4. Создайте `Dockerfile` в папке `task-docker/cmake-with-flask` со следующими шагами для контейнера:
   1. (1 point) В папке `/` должен быть файл README.md
   2. (1 point) В папке `/bin` должен быть исполняемый файл `./print_hello`, который печатает “Hello world” и ничего больше не делает
   3. (1 point) `git` должен быть установлен внутри контейнера.
   4. (2 point) Внутри проекта есть проект на `cmake`, он должен быть собран. Команды для сборки проекта на cmake: `mkdir build && cd build && cmake .. && make`. Команда для запуска процесса должна быть `bin/C`
   5. (2 points) Должен быть создан пользователь `devops2024user`, контейнер должен запускаться от имени этого пользователя. Это позволит избежать проблем при запуске приложения.
   6. (3 points) Приложение на Flask должно быть запущено при старте контейнера (система ожидает, что приложение запущено на порту 8898). Чтобы узнать опции запуска проекта, выполните команду `python3 app.py --help`.

## Требования

1. Используйте приватный репозиторий на Gitlab-е, при помощи которого вы сдали задание 0. Не забудьте проверить, что в коллабораторах есть `checker`.
2. В приватном репозитории создайте ветку `task-docker`, в нем создайте папку `task-docker`.
3. Положите созданный и работающий проект в папку `task-docker` в ветке `task-docker`.
4. Создайте Merge Request из ветки `task-docker` в ветку `main/master`, добавьте проверяющего в Merge Request и не сливайте этот Merge Request!
5. Необходимо добавить утилиту `which`: она будет использована для проверки наличия `git`.
