# Описание задания

## Bash. LU.

## Краткое описание

В этом задании Вам необходимо реализовать LU-декомпозицию входной матрицы.

---

## Процедура сдачи задания

1. В репозитории, в котором сдавали предыдущее задание, создайте ветку `bash/lu` из ветки `main/master`.
2. Создайте в новой ветке папку `bash/lu`.
3. В папке `bash/lu` создайте исполняемый скрипт `decomposition.sh`.
4. Отправьте SSH-ссылку на репозиторий в систему проверки.
5. Создайте Merge Request из ветки `bash/lu` в ветку `main`.  
   **Важно.** Если Merge Request не будет создан или в Merge Request будет конфликт, то задание автоматически отправляется на доработку.
6. Если задание будет решено верно, то задание попадёт на проверку преподавателю.
7. Если задание не будет решено полностью, то отправьте задание на проверку преподавателю.  
   **Важно.** не отправляйте задание на проверку преподавателю, пока не уверены. Посылка будет иметь терминальный статус.
8. В окружении установлена команда `bc` для вычисления арифметических выражений.

---

## Входные аргументы

1. Путь к файлу в формате CSV (Comma Separated Values)
2. Путь к выходной матрице `L` в формате CSV.
3. Путь к выходной матрице `U` в формате CSV.
4. Количество знаков после запятой в выходной матрице.

### Пример запуска скрипта

```
./decomposition.sh input.csv lower.csv upper.csv 5
```

---

## Требования

Все данные должны храниться в формате CSV (пожалуйста, найдите информацию в Интернете об этом формате)

- Входной файл может быть некорректным (он может не содержать символ LF в конце строки)
- Выходной файл может уже существовать. В таком случае вы должны перезаписать файл содержимым выходной матрицы.

Гарантируется, что все главные миноры входной матрицы ненулевые. Это гарантирует разложение матрицы.

Чтобы гарантировать единственность матриц `L` и `U`, диагональные элементы матрицы `L` должны быть равны 1.

**ВАЖНО.** Запрещено изменять входную матрицу. Если входная матрица в решении будет изменена после запуска скрипта, то тесты не будут пройдены.

---

## Пример

### Входные данные

- Входная матрица:

```
3,1,2
4,13,12
7,20,103
```

- Точность: 2

### Выходная матрица

Матрица L:

```
1.00,0.00,0.00
1.33,1.00,0.00
2.33,1.51,1.00
```

Матрица U:

```
3.00,1.00,2.00
0.00,11.67,9.33
0.00,0.00,84.20
```

## Советы и подсказки

Вам не требуется следовать всем подсказкам. Вы можете реализовать своё собственное решение.

- Bash не поддерживает многомерные массивы, поэтому вам следует либо использовать одномерные массивы, либо использовать ассоциативные массивы (предпочтительный вариант)
- Bash поддерживает только целочисленные вычисления. Используйте команду `bc`, чтобы работать с вычислениями с плавающей точкой.
- Округляйте вычисления только на последней стадии!
