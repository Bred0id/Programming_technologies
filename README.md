# Описание задания

## Git Submodules

10 баллов

## Краткое описание

Вам нужно добавить сабмодули, написать скрипт-помощник при клонировании репозитория и добавить собственный небольшой скрипт.

---

## Требования

1. Создайте ветку `git/sub` из ветки `main` репозитория.
2. Создайте папки `git/sub` (папку `git` и внутри нее папку `sub`).
3. Добавьте шаблон в качестве сабмодуля. Сохраните его в папке `server` внутри папки `git/sub`. Используйте http ссылку вместо ssh!
4. Добавьте `install.sh` скрипт, который содержит все команды необходимые для правильной настройки локального репозитория после клонирования.
5. Добавьте `runner.sh` скрипт

```
runner.sh COLOUR..
```

Скрипт `runner.sh` принимает на вход последовательность цветов (слова), после чего запускает сервис из сабмодуля (it is located inside `server` submodule). Дальше он посылает сервису по одному каждый из цветов и суммирует ответы сервиса. Не забудьте завершить работу сервиса!

- Для запуска сервиса исполните `service-init.sh`
- Для завершения работы сервиса выполните `service-shutdown.sh`

Для взаимодействия используются именованные пайпы: `in.fifo` & `out.fifo`. Они должны появиться в директории `server` сразу после запуска `service-init.sh`.

- Для того, чтобы отправить запрос, запишите его в `in.fifo`
- Чтобы получить ответ, прочтите из `out.fifo`

---

## Тестирование

1. (2 points) Simple

- Не больше одного аргумента на вход

2. (8 points) Complex

- Около 100 аргументов на вход

## Советы & Подсказки

Вы не обязаны следовать всем советам и можете реализовать любые свои идеи самостоятельно

- Сначала поэкспериментируйте локально с сервисом, прежде чем приступать к решению
- Документация
- Внимательно! Шаблонный репозиторий содержит рекурсивные сабмодули!
- Чтение и запись в именованные пайпы блокирующие: будьте аккуратны, чтобы не создать дедлок!
